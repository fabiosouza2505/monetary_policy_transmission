# monetary_policy_transmission
Este trabalho replica a arquitetura empírica de Ottonello andWinberry (2020) na economia brasileira, substituindo a variável de heterogeneidade: ao lado da posição financeira, introduzse o markup da firma, estimado pela abordagem de razão de custo. A pergunta central passa a ser se o poder de mercado condiciona a transmissão da política monetária.
